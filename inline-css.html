Understanding Generic Font Families

Generic font families are broad groups of fonts. Serif fonts have tiny feet on the letters. Sans-serif fonts are clean and have no feet. Monospace fonts use the exact same width for every single letter.

How to Add Color to Web Pages

You can add color to text in three main ways. First, you can use standard color names like red or blue. Second, you can use hex codes which look like numbers and letters. Third, you can use RGB codes to mix red, green, and blue light.
